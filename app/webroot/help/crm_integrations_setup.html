CRM Integration Help

This guide explains how to connect SMS, Email, Google Calendar, Facebook Lead Ads, and WhatsApp Cloud API with your White Villas CRM, how routing works, and how lead assignment stays isolated by agency, user level, and user login.

1. Overview

Your CRM integration module is designed to receive incoming leads and communications from external channels and save them into the same CRM workflow you already use. It does not change your lead business logic. It only adds new intake sources, sending gateways, and routing.

Current flow: Facebook and WhatsApp can push leads into CRM, SMS and Email settings control how the current logged-in user sends messages, and Google Calendar can sync lead follow-ups plus calendar tasks using either a global Google account or a private user Google account.
Important: live webhook receivers need a public HTTPS URL for production. localhost is fine for backend setup and local testing, but Meta cannot push production webhooks to localhost.

2. CRM Settings Page

The CRM Settings page now has five main areas:

  • SMS: lets each allowed user choose Use Global SMS Settings or Use My Own SMS Gateway, save gateway fields, and send a live test SMS.
  • Email: lets each allowed user choose Use Global Email Settings or Use My Own Email Gateway, save mail fields, and send a live test email.
  • Google Calendar: lets super admin save a shared Google app/account, lets each allowed user switch between Use Global Google Calendar or Use My Own Google Calendar, connect Google, and sync follow-ups plus calendar tasks.
  • Facebook Lead Ads: stores app credentials, tokens, webhook settings, default assignment, lead source, and contact-link setting.
  • WhatsApp Cloud API: stores business account details, number IDs, tokens, webhook settings, default assignment, lead source, and contact-link setting.
Field Purpose
Enabled Turns that provider integration on or off.
Use Global / Use My Own For SMS, Email, and Google Calendar, this decides whether the user keeps using the system-wide setup or saves a private setup only for that login.
Verify Token Must match the token used in Meta webhook verification.
Access Token Used by CRM to read or verify provider data.
Default Assignment Used only when no specific routing rule matches.
Test Button Lets you send one live SMS or Email, or test the saved Google Calendar connection before using it from leads and tasks.
Auto create/link contact If checked, CRM will create or link a contact along with the imported lead.

3. SMS Gateway Setup

  1. Open the CRM Settings page and choose SMS.
  2. Choose Use Global SMS Settings if this login should keep using your existing system SMS gateway.
  3. Choose Use My Own SMS Gateway if this login should send through its own private SMS provider settings.
  4. If you use your own gateway, fill the provider fields such as API Link, Sender ID, User Name, Password / API Key, and heading fields if your provider needs custom parameter names.
  5. Select the request method: Get or Post.
  6. Click Save SMS Settings.
  7. Use Test SMS Gateway with one mobile number before sending live messages from leads.
Lead messaging: after SMS setup, the normal Manage Leads > Send SMS and bulk SMS screens continue to use the same leads workflow, but they send according to the logged-in user mode: global SMS or that user's own SMS gateway.
User-level behavior: Agency, Agent, Manager, Marketing, CRM, and custom user levels can keep global SMS settings or switch to a private SMS gateway if that user level has permission to open CRM Settings.

4. Email Gateway Setup

  1. Open the CRM Settings page and choose Email.
  2. Choose Use Global Email Settings if this login should keep using your existing global Email configuration.
  3. Choose Use My Own Email Gateway if this login should send through its own private mail account or SMTP gateway.
  4. If you use your own gateway, fill the required mail fields like Type, Host, Port, Username, Password, and sender information.
  5. Click Save Email Settings.
  6. Use Test Email Gateway to send one live email before using bulk Email from leads.
Lead messaging: after Email setup, the normal Manage Leads > Send Email and bulk Email screens keep the same CRM flow, but send according to the logged-in user mode: global Email or that user's own Email gateway.

4A. Google Calendar Setup

  1. Open the CRM Settings page and choose Google Calendar.
  2. If you are super admin and want one shared calendar for everyone who chooses Use Global, fill the global Client ID, Client Secret, and optional Calendar ID, then save.
  3. If you want a private calendar for this login, choose Use My Own Google Calendar, fill your own Google app credentials, and save.
  4. Copy the callback URL shown on the page into your Google OAuth app redirect URL list.
  5. Click Connect Global Account or Connect My Account after saving credentials.
  6. Turn on Enable Google Calendar Sync, then choose whether to sync Lead Follow-up, Calendar Tasks, or both.
  7. Use Test Connection to verify the saved Google account, and use Sync My Upcoming Items once to push existing pending follow-ups and tasks.
Important: Google Calendar uses OAuth 2.0. Save credentials first, connect the account second, and only then enable live sync.
Sync behavior: when enabled, user lead follow-up changes and Calendar module task saves push to Google Calendar automatically for that same user scope.

5. Facebook Lead Ads Setup

  1. Open the CRM Settings page and choose Facebook Lead Ads.
  2. Fill App ID, App Secret, and Page Access Token.
  3. Set a Verify Token. Use exactly the same token inside Meta webhook settings.
  4. Copy the CRM Webhook URL shown on the page and register it in Meta webhook configuration.
  5. Select default Agency, User Level, and User.
  6. Set optional default lead status and lead source label.
  7. Click Save Facebook Settings.
Production note: Meta requires a public secure callback URL. Replace localhost with your live domain before final activation.

6. WhatsApp Cloud API Setup

  1. Open the CRM Settings page and choose WhatsApp Cloud API.
  2. Enter Business Account ID, Phone Number ID, Access Token, and Verify Token.
  3. Copy the CRM Webhook URL shown on the page and register it for WhatsApp webhook events.
  4. Select default Agency, User Level, and User for unmatched messages.
  5. Set default status and lead source if needed.
  6. Click Save WhatsApp Settings.
Current behavior: incoming WhatsApp messages can create a new lead or update an existing CRM lead path depending on your existing matching logic.

7. CRM Routing Rules

Use CRM Routing when one provider should send different sources to different teams or users.

  • Facebook route types: Form ID, Page ID
  • WhatsApp route type: Phone Number ID

Routing priority is:

  1. Matched route rule
  2. Provider default assignment from CRM Settings
Example: If Facebook Form A should go to Marketing and Facebook Form B should go to CRM team, create two routing rows with different external source IDs.

8. Isolation by Login / Agency / User

Yes, the CRM integration assignment choices are isolated by the logged-in user scope.

  • Page access follows your normal page_rights system.
  • Super Admin keeps full access across all modules and assignments.
  • If you assign rights to another user level, that level can access the page only if its page rights allow it.
  • Agency and user dropdowns are loaded through your existing scoped helper logic, so non-global users should only see allowed agencies and users inside their own scope.
  • SMS, Email, and Google Calendar choice is also per logged-in user. One user can keep global settings while another user on the same level can use a private gateway or Google account, depending on saved CRM settings and permission.
Meaning: the integration is not bypassing your login or role system. It is using the same user, role, and agency permission structure already active in backend.

9. Testing Checklist

  1. Save SMS settings and send one test SMS if you plan to use SMS from leads.
  2. Save Email settings and send one test Email if you plan to use Email from leads.
  3. Save Google Calendar settings, connect the Google account, and use Sync My Upcoming Items once if you plan to use calendar sync.
  4. Save Facebook or WhatsApp settings successfully.
  5. Create one test route rule if you need source-based routing.
  6. Send a test lead or message from the provider.
  7. Check CRM Sync Logs for saved event status.
  8. Open Manage Leads and confirm the record or send-action uses the expected assignment and gateway mode.
  9. Check whether contact linking is on or off depending on the checkbox setting.

10. Troubleshooting

  • SMS not sending: confirm whether the user is set to Use Global or Use My Own, then re-check API link, sender ID, credentials, and Get/Post method.
  • Email not sending: re-check whether the user is using global or private gateway, then verify host, port, username, password, and sender email.
  • Webhook verification fails: re-check the exact verify token and public HTTPS URL.
  • No lead imported: confirm the provider is enabled and the access token is valid.
  • Wrong assignment: review CRM Routing rules first, then provider default assignment.
  • Lead saved but not linked as contact: check whether Auto create/link imported leads as customer contacts is enabled.
  • Localhost works only in backend but not from Meta: this is expected until a public live domain is used.
